# Pandas Data Analysis Practice

This repository contains a Jupyter Notebook (`pandas` exercises) covering foundational data analysis and data cleaning operations in Python.

## Topics Covered

* **DataFrame Creation & Inspection:** Creating DataFrames from dictionaries and inspecting structure/summary statistics with `.info()`, `.describe()`, and `.head()`.
* **Conditional Filtering & Sorting:** Filtering rows based on numeric/boolean conditions and sorting values with `.sort_values()`.
* **Feature Engineering:** Calculating new columns (e.g., weighted exam averages and price markups).
* **Grouping & Aggregation:** Summarizing datasets by category using `.groupby()` with `.max()` and `.mean()`.
* **CSV I/O:** Exporting DataFrames to `.csv` files (`to_csv`) and reading them back (`read_csv`).
* **Data Cleaning:** Detecting and handling missing values (`isna`, `fillna`, `dropna`), removing duplicates (`drop_duplicates`), type casting (`astype`), and normalizing text strings (`.str.strip()`, `.str.lower()`).
